## Features
- **Encode & Decode**: Shift letters forward or backward in the Turkish alphabet.
- **Custom Shift Values**: Supports dynamic integer shift values using modulo math.
- **Input Validation**: Handles non-numeric shift inputs and preserves special characters/spaces.

## Module Architecture
- `main.py`: Handles the user interface, loop control, and CLI input flow.
- `modules.py`: Contains language settings, letter lists, input validator, and encoding/decoding functions.
